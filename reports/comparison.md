# YOLO 模型导出与推理性能对比报告

## 1. 实验目的

比较同一 YOLO pose 模型在 PyTorch、ONNX、TorchScript 和 OpenVINO
运行格式下的模型体积、推理延迟、吞吐量及检测数量，并评估 ONNX 与
OpenVINO 的 FP16 导出结果相对于 FP32 的变化。

本报告记录当前一次完整视频基准测试的实测数据，不将单轮测试视为多次重复实验的统计结论。

  CPU            Intel Core i5-7200U 2.50 GHz（导出日志）

运行设置。由于 PyTorch 环境未启用 CUDA，本次没有进行 GPU/TensorRT
测试，也没有生成 TorchScript FP16 模型。

## 4. FP16 与 FP32 对比

### 4.1 ONNX

  指标               ONNX FP32     ONNX FP16           变化
  -------------- ------------- ------------- --------------
  模型大小            9.724 MB      4.927 MB   减少约 49.3%
  平均推理耗时     132.6017 ms   130.4229 ms    降低约 1.6%
  平均 FPS              7.5414        7.6674    提高约 1.7%
  检测总数                 769           771         增加 2

本次测试中，ONNX FP16
明显降低了模型文件体积，但平均推理速度只出现小幅变化。该结果来自 CPU
上的 ONNX Runtime，不能据此推断 FP16 在 GPU 上也会获得相同的加速比例。

### 4.2 OpenVINO

  指标             OpenVINO FP32   OpenVINO FP16           变化
  -------------- --------------- --------------- --------------
  模型大小              9.878 MB        5.265 MB   减少约 46.7%
  平均推理耗时        87.2455 ms      86.8170 ms    降低约 0.5%
  平均 FPS               11.4619         11.5185    提高约 0.5%
  检测总数                   771             771         无变化

在当前 CPU 环境中，OpenVINO FP16 的模型体积更小，但平均延迟与 FP32
几乎相同。两者检测总数相同，但检测总数一致并不等价于每一帧的框、类别和关键点都完全一致。

## 5. 结果解读

1.  **模型体积方面：** FP16 导出有效降低了 ONNX 和 OpenVINO
    模型的磁盘占用，减少幅度分别约为 49.3% 和 46.7%。
2.  **推理速度方面：** 本轮数据中 OpenVINO 的平均推理速度最快，FP16 与
    FP32 的平均延迟差异很小。
3.  **延迟稳定性方面：** OpenVINO 的 P50 约为 36--38 ms，但 P95 超过 300
    ms，说明部分帧出现了较长延迟。仅报告平均值会掩盖尾部延迟，需要进一步重复测量并检查系统负载、运行时初始化及个别帧开销。
4.  **检测数量方面：** PyTorch 记录 747 个检测，ONNX/TorchScript 记录
    769--771 个，OpenVINO 记录 771
    个。导出格式、数值精度和后处理实现都可能造成差异。需要结合相同帧的可视化结果或逐框匹配进一步判断，而不能直接把检测数量更多视为准确率更高。
5.  **基准公平性方面：**
    所有格式在相同视频和参数下测试，但目前每种模型只有一轮完整视频测试。不同模型的执行顺序、系统负载和运行时缓存可能影响结果；小于几个百分点的速度差异不应被表述为确定性的性能优势。

## 6. 当前实验限制

-   本次只在 CPU 上测试；没有测试 CUDA、TensorRT 或 GPU FP16。
-   TorchScript 仅测试 FP32。当前环境未检测到可用 CUDA，因此未生成
    TorchScript FP16。
-   本次是单轮完整视频测试，尚未进行多轮重复运行及置信区间分析。
-   检测总数只是整体统计，不等同于 mAP、精确率、召回率或逐帧一致性评估。
-   P95 延迟较高，建议在固定系统负载下重复至少 3
    轮，并报告各轮结果及中位数。

## 7. 复现命令

在项目根目录、已激活对应 Python 环境的 PowerShell 中执行：

``` powershell
python .\benchmark.py
```

查看 CSV：

``` powershell
Import-Csv .\reports\benchmark_results.csv |
    Format-Table model_id, precision, model_format, model_size_mb,
        avg_inference_ms, p50_inference_ms, p95_inference_ms,
        inference_fps, total_detections, status -AutoSize
```

重新提取相同视频帧的可视化对比图：

``` powershell
python .\extract_frames.py
```

## 8. 结论

在本次 CPU 基准测试中，OpenVINO 获得了最低的平均推理延迟；ONNX FP16 和
OpenVINO FP16 均显著减小模型文件体积，但在当前硬件与运行时组合下，FP16
的平均推理速度提升有限。部署格式的选择应综合考虑目标硬件、模型大小、延迟分布、检测结果一致性及部署依赖，而不应仅依据单轮测试的平均
FPS 作出判断。
