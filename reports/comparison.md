# YOLO 装甲板模型导出与推理性能对比

## 1. 实验目的

以原始 PyTorch `.pt` 权重作为基准，将同一模型导出为 ONNX、TorchScript 和
OpenVINO
格式，并在相同测试视频及推理参数下比较模型文件大小、推理耗时、FPS
和检测数量。

## 2. 实验环境与固定参数

-   测试视频：`videos/original.mp4`

-   测试视频帧数：483

-   预热帧数：10（不计入 measured frames）

-   计时帧数：473

-   输入尺寸：`imgsz=640`

-   置信度阈值：`conf=0.31`

-   IoU 阈值：`iou=0.70`

-   推理设备：CPU

-   测试状态：四种格式均为 `OK`

-   测试记录时间：`2026-10-23T20:15:13+08:00`

> 注：CSV 中的 `model_size_mb` 是由脚本按字节数除以 1024²
> 计算的，因此本报告用 MiB 表示该字段。

## 4. 结果分析

### 4.1 模型文件大小

PT 基准模型为 5.619 MiB，是四种格式中最小的。ONNX、TorchScript 和
OpenVINO 导出产物分别为 9.724 MiB、9.946 MiB 和 9.878
MiB。导出格式并未在本实验中减少文件体积；OpenVINO
的大小按整个模型目录统计。

### 4.2 推理速度

本次单轮测试中，OpenVINO 的平均推理耗时最低，为 102.19 ms，推理 FPS 为
9.79；相对 PT 的平均推理耗时降低 7.9%，FPS 提高 8.6%。

ONNX 平均推理耗时为 146.88 ms，较 PT 高 32.4%；TorchScript 为 169.68
ms，较 PT 高 52.9%。因此，在当前 CPU、软件版本和测试设置下，导出为 ONNX
或 TorchScript
并没有带来更快的推理速度。此结果仅适用于当前实验环境，不能泛化为这些格式在所有硬件上都更慢。

### 4.3 OpenVINO 的延迟波动

OpenVINO 的 P50 为 42.17 ms，而 P95 为 368.68 ms，二者差距较大；其 P95
也高于 PT 的 154.96
ms。该现象说明本轮测试存在明显的长尾延迟或个别帧耗时尖峰。仅凭这一份汇总
CSV
无法确定具体原因，可能需要进一步检查线程调度、运行时初始化、系统后台负载或计时方法。应重复测试并比较多轮统计，再判断
OpenVINO 的性能稳定性。

### 4.4 检测数量与结果一致性

PT 检测总数为 747；ONNX 和 TorchScript 均为 769；OpenVINO 为 771。相较
PT，ONNX/TorchScript 多检出 22 个，OpenVINO 多检出 24 个。

检测数量差异不等同于精度提升。要确认模型输出是否一致，需要在相同帧上逐个比较类别、置信度、检测框及四个姿态关键点。当前
CSV 没有提供人工标注真值、Precision、Recall、mAP
或逐帧匹配信息，因此不能据此判断哪个格式检测准确率最高。

## 5. 实验限制与改进建议

1.  **目前为单轮结果。** 建议在相同环境下至少重复运行 3
    轮，记录每轮平均耗时、P50、P95 和 FPS，并报告均值或中位数。
2.  **统一计时口径。** 确认 `avg_inference_ms`
    是否仅计算模型推理；视频解码、绘制检测结果和编码输出视频的时间应与模型推理时间区分。
3.  **检查视频结果。**
    查看四个输出视频相同时间点的检测框、类别、置信度和 LT/LB/RB/RT
    关键点。
4.  **检测效果需要真值评估。**
    如果没有标注数据，应将结论限定为输出数量与可视化结果对比，不应声称精度更高。
5.  **记录软件环境。** 在 README 中补充
    Python、PyTorch、Ultralytics、ONNX Runtime、OpenVINO 和 CPU
    信息，以便复现实验。

## 6. 初步结论

在本次 CPU 单轮测试中，OpenVINO 获得了最低的平均推理耗时和最高的平均
FPS，但其 P95 延迟明显偏高，稳定性仍需重复测试确认。PT
模型文件最小；ONNX 和 TorchScript
在当前环境下未表现出速度优势。不同格式的检测总数略有差异，因此还需要检查具体帧的检测框、类别与关键点，不能仅根据总数判断检测质量。
